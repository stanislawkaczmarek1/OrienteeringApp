# Orienteering App 🗺️🏃‍♂️

This repository contains the backend implementation for the Orienteering App ecosystem.

The ecosystem consists of this backend service, a mobile application, and a web application.

The mobile application is used for daily training activities and provides a cloud synchronization feature, which is handled by this backend. 
The web application allows users to follow the training results of other athletes and access personal performance statistics.

The backend serves as a central service layer for both client applications, providing RESTful APIs.
It is implemented using Onion Architecture, ensuring a clear separation between domain logic, controllers, application services, and infrastructure concerns, which improves maintainability and scalability.
